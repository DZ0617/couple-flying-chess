# 情侣飞行棋 · Couple's Ludo

一款专为情侣设计的飞行棋游戏，包含趣味任务、互动挑战、Hearts 经济与心愿系统。

## 功能

- **四种模式**：经典 / 双骰狂欢 / 真心话 / 渐进之夜（温度引擎）
- **12 种棋盘格子**：幸运、陷阱、双人、前进/后退、飞跃、漩涡、护盾、交换、再来一次、默契考验
- **Hearts 经济**：局内 Hearts + 心愿银行、爱心商店、心愿商店（18 件四档）、征服图鉴
- **渐进之夜**：温度 0~100，五温度带，闸口升温由双方共同决定，默契格、欠账、败者惩罚
- **分享**：Canvas 生成心愿券分享卡（零依赖）
- **体验**：响应式双栏、音效系统、3D 翻卡、昵称自定义、七夕限定事件

## 本地运行

```bash
npm install
npm run dev
```

## 技术栈

Vite + React 18 + TypeScript + Tailwind CSS，纯前端无后端，localStorage 持久化。

## 部署

推送到 master 分支后，GitHub Actions 自动构建并发布到 GitHub Pages。
